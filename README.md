# 💱 Currency Converter

**Автор:** Софьин Егор Юрьевич
**Версия:** 1.0

## Описание программы

«Currency Converter» — это графическое приложение для быстрой конвертации валют по актуальному курсу. Программа использует внешний API для получения данных и сохраняет историю ваших операций.
*   **Точность:** Использует официальные курсы валют.
*   **История:** Все ваши конвертации сохраняются локально.
*   **Удобство:** Простой интерфейс с выбором валют из списка.

## Системные требования и установка

1.  **Python 3.8+**
2.  **Библиотеки:**
    *   `tkinter` (входит в стандартную библиотеку).
    *   `requests` (для работы с API).
3.  **Установка зависимостей:**
    ```bash
    pip install requests
    ```

## Как получить API-ключ

Для работы приложения требуется бесплатный API-ключ от [ExchangeRate-API](https://www.exchangerate-api.com/).
1.  Перейдите на сайт и зарегистрируйтесь.
2.  Скопируйте ваш **API Key**.
3.  Откройте файл `main.py`.
4.  Замените строку `API_KEY = 'YOUR_API_KEY'` на ваш ключ.
   ```python
   API_KEY = 'sk_123456789yourkeyhere'
   ```

## Запуск приложения

1.  Убедитесь, что Python и библиотека `requests` установлены.
2.  Запустите скрипт из терминала в папке проекта:
    ```bash
    python main.py
    ```
3.  Введите сумму и выберите валюты для конвертации.

## Примеры использования (Тесты)

| **Действие** | **Ввод / Действие** | **Ожидаемый результат** |
| :--- | :--- | :--- |
| **Тест 1: Базовая конвертация** | Сумма: `100` <br> Из: `USD` <br> В: `EUR` <br> Кнопка «Конвертировать» | В поле «Результат» отображается сумма в Евро. Вкладка «История» пополняется новой записью. |
| **Тест 2: Ошибка ввода (ноль)** | Сумма: `0` <br> Из: `USD` <br> В: `RUB` <br> Кнопка «Конвертировать» | Появляется окно с ошибкой: «Сумма должна быть больше нуля». |
| **Тест 3: Ошибка ввода (текст)** | Сумма: `сто` <br> Из: `USD` <br> В: `GBP` <br> Кнопка «Конвертировать» | Появляется окно с ошибкой: «Пожалуйста, введите положительное число в поле суммы». |
| **Тест 4: Просмотр истории** | Перейти на вкладку «История» | Отображается таблица с датой, суммой и курсом обмена для последних операций. |
